# Bibek Portfolio Website (Next.js + Tailwind)

This portfolio has been migrated from React + Vite to Next.js App Router with Tailwind CSS.

## Tech Stack

- Next.js (App Router)
- React
- Tailwind CSS
- React Icons

## Development

Install dependencies:

```bash
npm install
```

Run dev server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Start production server:

```bash
npm run start
```

## SEO Features Included

- Metadata via `src/app/layout.jsx`
- Open Graph and Twitter metadata
- JSON-LD person schema on the homepage
- `robots.js` and `sitemap.js`
